Arquivo de informacoes sobre as logos dos canais

Este arquivo registra a finalidade da pasta de logos: armazenar uma imagem PNG individual para cada canal, mantendo cada logo associada ao canal correto.

O arquivo README anterior informava que 214 logos haviam sido restauradas do historico do repositorio e colocadas em fundo preto. Essa observacao descreve a geracao anterior, que foi removida a pedido do usuario por nao seguir a demonstracao aprovada.

Nenhuma logo foi recriada ou adicionada nesta pasta. A TV principal e os links dos canais nao sao alterados por este documento.
