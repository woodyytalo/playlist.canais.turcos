# Acervo de logos de canais de TV da Turquia

Este diretório organiza as fontes para reunir logos de canais turcos sem misturar imagens de canais que não estão na playlist principal.

## Catálogo de referência

- [Wikimedia Commons — Logos de canais de televisão da Turquia](https://commons.wikimedia.org/wiki/Category:Logos_of_television_channels_in_Turkey)
- [Wikimedia Commons — Logos SVG de canais de televisão da Turquia](https://commons.wikimedia.org/wiki/Category:SVG_logos_of_television_channels_in_Turkey)
- [LyngSat Logo — TV from Turkey](https://www.lyngsat.com/logo/tvcountry/Turkey.html) — catálogo para identificação e conferência visual; não copiar/republicar arquivos sem autorização.

## Regras para adicionar arquivos

1. Verificar a página individual de cada arquivo e registrar a licença e a atribuição exigida.
2. Priorizar logos atuais e originais do próprio canal; não usar versões históricas quando houver uma atual confirmada.
3. Não presumir que uma imagem é reutilizável apenas por aparecer em um catálogo. Arquivos do Wikimedia Commons têm licenças individuais; conferir cada uma.
4. Manter os arquivos finais em PNG quadrado de 256×256 px, fundo preto uniforme, logo original centralizada, cores preservadas e sem deformação.
5. Guardar cada logo neste diretório com nome de arquivo identificável pelo canal. Não alterar streams, nomes, categorias ou ordem da playlist ao montar o acervo.

## Estado inicial

Este arquivo registra as fontes e os critérios do acervo. As imagens ainda precisam ser obtidas individualmente de fontes com licença compatível ou autorização; nenhuma imagem protegida do LyngSat foi copiada para este repositório.
